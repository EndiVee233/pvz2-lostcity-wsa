## 构造、继承和属性

原元数据入口 `00444b2c`、工厂 `00442f3c` 及删除析构 `0044401c` 实际执行。LevelDefinition 的父类是 **PropertySheetBase**，而非 LevelModuleProperties，因此不具有 ResourceGroupNames。原模式的计算属性列表为空。

37 个注册字段包括继承的 m_thisPtr 和以下数据：

| 字段组 | 恢复范围 |
| --- | --- |
| 关卡文本 | Name、Description、MainObjective、challengeDropGroupId、礼物表、奖励参数、四个叙述文本、ForceNextLevel、CompletionAchievement、MusicType，共 15 个窄字符串 |
| 数值 | StartingSun、LevelNumber、LevelIndex、ZombieMaxLevel |
| 引用 | StageModule、VictoryModule、Loot 和 Modules 列表 |
| 奖励 | FirstRewardType、ReplayRewardType 的窄文本枚举 |
| 标志 | 胜利/失败画面、关卡类型等 9 个 bool 字段 |
| 僵尸警告 | ZombieWarningInfos，每项为 Type 引用、Text 文本、Level 整数 |
| 功能解锁列表 | 选定原注册环境中的 GameFeature 元素读取器未解析，仅保留原向量调整大小/默认槽行为；不宣称解锁值已恢复 |

工厂默认值经原指令确认：StartingSun=50、LevelNumber=0、LevelIndex=-1、ZombieMaxLevel=-1；MainObjective 为 `[SURVIVE_ZOMBIE_ATTACK]`；两个奖励类型为 collectable（2），参数均为 moneybag；GameOverDialogShowBrain=true，其余标志为 false；引用和列表为空。

StartingSun 的原存储宽度是 16 位。读取 int32 后按原短整数写入保留低 16 位，未用宿主 int32 替代；检查包含 -1、32767、32768、65535、65536 和 int32 两端值。工具同时输出签名短整数值和 StartingSun_bits。

奖励枚举从真实名称树读取确认，包含 none、present、collectable、seed_packet、powerup 等十五项；保留去 ASCII 空白、大小写敏感匹配和 signed32 范围内的十进制回退。当前仍限定窄文本/缓存窄文本，未恢复全部数值或宽文本强制转换。

窄字符串保留原 C 字符串首零截断规则。Modules 的每个元素均拥有弱引用所需的驻留计数；列表缩容时按原顺序释放被移除的引用。警告记录更新重叠项、保留缺少成员，新项默认为空 Type/Text、Level=0。销毁时按原代码依次释放警告引用、Loot、Modules、VictoryModule、StageModule，最后进入继承字段清理。

## GameFeature 的明确缺口

本轮直接检查了 GameFeaturesToUnlock 的元素描述符：类型名 GameFeature，对应 `011ab2bc`。在所选原始注册环境中，其读取路径立即返回 0，目标字保持原值。原向量仍会调整到输入数量并产生默认零槽，但元素内容没有解码。

源码保留这项实测行为，并在工具中输出 `GameFeaturesToUnlock_values_read: false`。这不表示原完整游戏的所有注册环境都无法读取 GameFeature，也不表示游戏功能已解锁。原元素枚举注册、完整模式构建和相关游戏行为仍需恢复。汇编及直接调用结果保存在本轮证据中。

## 真实资源的本包连接

输入继续使用 APK 内置工具资源 `assets/pvz2tool/features/level_replace_enable/COWBOY_DANGERROOM.RTON` 的既有解密明文，没有删减或重新编码声明。

最新工具把当前对象库的包别名配置为 **CurrentLevel**，与真实资源中的引用名称一致。原 ARM 取证使用相同调用方配置；尚未声称原游戏建立对象库、定位关卡文件和初始化场景的完整调用链已移植。历史工具范围仍保留 local 包别名，分别验证。

源码和原 ARM 输出的五个对象为：

| 声明序号 | 类 | LevelDefinition.Modules 中的本包连接 |
| --- | --- | --- |
| 0 | LevelDefinition | 根配置 |
| 1 | WaveGeneratorProperties | Waves → 1 |
| 2 | DangerRoomLevelIntroProperties | DangerRoomIntro → 2 |
| 3 | RailcartProperties | Rails → 3 |
| 4 | SeedBankProperties | SeedBank → 4 |

九项 Modules 的目标序列为 `2, null, null, null, null, 1, 3, 4, null`。其中五项指向尚未加载的 LevelModules；StageModule、Loot、默认英雄和僵尸池也涉及外部对象。整个输出共有 16 条非空外部符号引用尚无已加载目标，未创建替代对象冒充解析成功。

另外三份既有 Festival 资源现在分别创建 LevelDefinition 和 SeedBankProperties，即 2/6 个声明对象；其余类仍为空。
