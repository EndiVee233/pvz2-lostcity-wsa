# 第四轮恢复结果

主库累计有 **55,202 个不同地址的函数伪代码**，较第三轮新增 2,310 个。新增目录包含 80 个从独立工程导出的实验候选，来源和旧版本均保留。

- 类型目录：字段、方法、虚函数槽位（本地材料）
- Zombie：补出的 79 个字段登记（本地材料）
- GetHitpoints：登记名称、字段偏移与指令证据（本地材料）
- 214 条反射方法对应记录（本地材料）
- 统一函数目录（本地材料）
- 候选与历史来源（本地材料）
- 未采用的实验候选与原因（本地材料）

修正了 3 个已有反编译结果的 UTF-8 保存错误。原先 5 个大型函数现在均有 C 候选输出；其中 Zombie 的注册回调还恢复出 `m_hitpoints`、`m_maxHitpoints`、`m_damageScale` 等 79 个字段登记。

新入口由虚函数表或原生方法描述符中的代码指针支持。对落在其它函数内部的入口，另建工程试验边界，原主工程的旧函数边界保留。库的 ELF 属性标记 ARM v7，因此额外使用 ARM v7 解码设置与原 ARM v8 默认设置对照。

## 尚未解决的部分

对旧的 415 个控制流截断输出进行了独立工程对照。按函数范围、警告及截断标记的保守规则，本轮自动采用的替换数为 0；更好看的输出也可能来自错误边界，实验文件不等于验证通过。

以下原困难条目仍未纳入主目录：`00a1580c`, `01023a3c`, `01454c64`, `01491afc`, `01493eb0`。其中 `00a1580c` 有实验 C 输出，但覆盖范围与基线差异过大，留待人工核对。

目前统一目录还有 420 个带控制流截断标记的输出（包括本轮新增候选），并有类型、间接调用等未验证之处。新旧原始输出分别保存在各批次目录；这不是可直接编译的原始游戏工程。原 APK 未修改。
