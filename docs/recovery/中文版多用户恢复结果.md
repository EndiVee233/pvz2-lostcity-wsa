## 定位与修复

中文版原生库仍包含北美版同类的玩家列表、添加行、新建/编辑页、删除确认框及相关中文文本与素材，不需要移植北美版资源。初查的 `UI_Profile_select` 是云端/本地存档对比界面，真正的多玩家列表是另一组原生类。

昵称按钮在 `FUN_00472378` 中仍以按钮 ID `3` 创建，但 `FUN_00470d18` 的分发分支直接跳到返回处。已有 `FUN_00474770` 负责打开列表，内部调用列表构造函数 `FUN_00474470`，随后将其加入原有界面容器。

此次仅修改原库文件偏移 `0x00460d54` 处的一条 ARM 指令（Ghidra 地址 `0x00470d54`）：将 `B epilogue` 改为 `BL 0x00474770`，返回后落入下一条仍跳向返回处的分发表指令。保持函数栈平衡。4 字节指令中实际改变 3 字节，没有注入新界面或替换存档格式。

对原始分发器完成 32 项有界 ARM 仿真，覆盖启用/禁用菜单状态及按钮 3、4、5、6、7、8、9、11 的原始和修复版本。仿真中列表打开函数由钩子替代；真实界面行为由 WSA 实测另行确认。
