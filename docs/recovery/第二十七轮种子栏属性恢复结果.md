## 原字段与默认值

原工厂 `008a82a8` 分配 `0x50` 字节；类型元数据入口 `008ab974` 继承 `LevelModuleProperties`。字段注册回调 `008ab9f4` 在既有伪代码导出中缺失，本轮执行真实回调读取完成后的模式，并补存该函数和元数据函数的汇编。字段按注册顺序为：

| 字段 | 原偏移 | 本轮数据实现与默认值 |
| --- | --- | --- |
| `m_thisPtr` | `0x08` | 继承的弱引用，默认空 |
| `ResourceGroupNames` | `0x10` | 继承的资源组字符串列表，默认空 |
| `SelectionMethod` | `0x1c` | 窄文本枚举；`preset=0`、`chooser=1`，默认 1 |
| `AlwaysUseChooser` | `0x20` | bool，默认 false |
| `ZombieMode` | `0x21` | bool，默认 false |
| `GridItemMode` | `0x22` | bool，默认 false |
| `PlantWhiteList` | `0x30` | 窄字符串列表，默认空 |
| `PlantBlackList` | `0x3c` | 窄字符串列表，默认空 |
| `BlackListLiftedBy` | `0x48` | 窄字符串，默认空 |
| `PresetPlantList` | `0x24` | 窄字符串列表，默认空；注册顺序在最后 |

原枚举名称树中的名称、值及非位标志属性经真实模式读取确认，记录在 `seedbank_selection_enum`。读取沿用去 ASCII 空白、大小写敏感匹配和有界十进制回退：未知文本按原 atoi 路径处理，默认零；不会把 `preset|chooser` 当成位标志集合。当前枚举输入限定窄文本及缓存窄文本，未恢复数字/宽字符串等全部强制转换。

三个 bool 属性接入此前已恢复的非 RTID 标量读取，验证真实 JSON 布尔值、整数、浮点及文本输入。原窄文本布尔规则判断首字符，因此字符串 `"false"` 得到 true、`"0abc"` 得到 false；这不同于 JSON 布尔值 false，本轮保留原规则。RTID 布尔转换仍未接入。

植物名单是普通字符串列表，保留次序、重复项和空字符串。更新某一名单会替换该名单，缺少字段保留已有内容，空列表清空；缓存字符串、首个零字节截断和 UTF-8 窄字节文本均与原 ARM 对照。没有把字符串名单实现成弱引用列表，任意类型转字符串仍不支持。

## 源码接入

新增 `register_seedbank_class()`，沿已有父类注册，并保持重复调用不重复登记。宿主共用数据构造器增加相应默认字段；它不等于恢复原虚表、ARM 对象布局或类的游戏方法。

本轮将既有 GroundEffect 枚举规则抽为共用的有界枚举读取，将资源组、植物名单和类型文本使用的窄字符串读取统一。所有前轮检查继续通过。实际填充遵循注册顺序，特别保留 PresetPlantList 在最后的行为，以及上一轮已确认的错误列表类型导致后续字段读取范围变化的规则。完整原序列化上下文栈、任意畸形输入跨对象传播仍未实现。

`m_thisPtr` 继续使用真实两遍加载、别名/包索引、符号句柄所有权和解析规则，可与开场对象形成循环引用，或引用后加载的其他包对象。重置、对象销毁和重建后的整个驻留池及对象库状态均在检查范围内。

## 真实资源与独立工具

Cowboy 输入仍为 APK 内置工具中的 `assets/pvz2tool/features/level_replace_enable/COWBOY_DANGERROOM.RTON` 解密明文。未删除或重新编码其中其他对象。源码与仅注册本轮选定类的原 ARM 环境输出一致：

- 声明 2：开场配置，保留原工厂默认参数。
- 声明 3：矿车配置，读取原轨道与矿车坐标。
- 声明 4：种子栏配置，SelectionMethod=1、AlwaysUseChooser=true，其他模式为 false，植物名单及 BlackListLiftedBy 为空。
- 声明 0、1：尚未支持的两个类，保留空项。

另外三份已有 Festival 关卡替换资源也已完成原 ARM/C++ 图对照，各能装载 1/6 个声明对象，即种子栏；其中 `PlantBlackList` 包含的 `iceburg` 等原字符串按原样读取。来源路径及明文摘要均记录在证据中。这是 APK 资源中的部分数据装载，不是完整原版关卡或源码游戏运行。

工具默认支持九类；`--railcart-only` 保留第二十六轮八类范围，`--intro-only` 保留第二十五轮七类范围。部分资源输出仍返回 `3`，表明有未支持的工厂；JSON 的 `success` 是原装载遍历返回值，不表示完整关卡支持。聚焦循环图返回 `0`。
