# 第十八轮：包路径、别名切换与非空包注销

新增 `engine_package_paths`，将包路径规范化、资源文件名生成和包别名生命周期接入 `OwnedStore`。本轮扩展了上一轮仅包编号为零的验证范围；源码模块可以独立构建，完整游戏仍不能脱离原引擎运行。

## 恢复依据

| Ghidra 地址 | 行为 |
| --- | --- |
| `011ebe2c` | 设置包、切换类型名称别名、引用管理及文件名更新 |
| `011e71c4` | 去末尾扩展名、转换分隔符、去 packages/ 前缀 |
| `011e6f10` | 生成 packages/ 路径和 .rton 文件名 |
| `011450b8`、`011473ac`、`011471cc` | 目录、去扩展名的基本名、UNC/驱动器基本名定位 |
| `01141e38`、`01141d80` | 宽字符取低字节、无符号字节扩为宽字符 |
| `011e63b4` | 优先选择包名，否则选择对象库名 |

路径转换不是 UTF-8 编解码。原宽字符串的每个字符只保留低八位；逻辑字符串中的零字节在部分分支仍被保留。packages/ 比较忽略大小写，长度 9 来自原 `_INIT_1265` 对 `018cbf6c` 的赋值。取证显式设置此常量，未运行还会注册无关 RTTI 的完整初始化函数。

同一规范包名再次设置会提前返回，保留首次生成的文件名。包别名和对象库名共用类型名称树：冲突会覆盖，删除时不核对当前归属，同名提前返回也不会修复被其他对象库移除的映射。源码保留原行为，未增加自动修复。

注销先硬重置、删除对象库名，再清包别名，随后移除双表项和释放对象库名。非空包注销、调用方释放输入路径后的包存活、包名解析对象及软/硬重置已纳入对照。

## 验证

92 个原 ARM 场景共 462 个检查点：40 个纯路径场景、120 个输出检查；52 个 owner 场景、342 个完整状态检查。每步核对原驻留池引用和树、类型名称树、槽位及索引、包编号、逻辑文件名、选中名称、回调和销毁观察值。覆盖中文、非 BMP、低字节零、大小写、UNC、驱动器、点文件、重复扩展名、目录和包别名冲突。

原设置函数、路径函数、COW 字符串、驻留树和对象库注销实际执行。受控边界为分配器、libc 原语、单线程 kuser 比较交换及外部对象/注册表回调体。宿主实现使用 std::string/std::u32string 和显式 owner，不复现原 Android COW/指针 ABI。
