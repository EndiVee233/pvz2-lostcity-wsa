# 第三十三轮：僵尸失败边界配置恢复

本轮恢复 ZombiesAteYourBrainsProperties 的数据工厂及 ZombieWinPositionX 浮点属性，并准备同步第八至第三十三轮累计源码到已有 GitHub 仓库。

## 取证和源码

原类型入口 `00b75f44`、工厂 `00b75c2c` 与实际模式注册确认该类继承 LevelModuleProperties，分配大小为 `0x20`。继承字段 m_thisPtr 位于 +8，ResourceGroupNames 位于 +0x10，直接字段 ZombieWinPositionX 为 +0x1c 的 float，原工厂默认位模式为 `0xc2a00000`，即 -80.0。

真实工厂、反射管理器、规范化、两遍对象装载和字段读取执行。八个连续状态覆盖默认值、真实资源对应的 -80、不同负数、缺失字段保持、正零、负零、窄文本十进制和未知字段忽略。C++ 逐项 float32 位模式与原 ARM 一致。本轮比较直接字段，不宣称完整注册表/驻留池状态、任意强制转换或畸形上下文等价。

新增 `register_brain_properties_class()` 可启用第十五种具体数据类；CLI 的默认十一类与此前可选模式保留其各自范围，新配置通过库 API 和 `brain_package_tests.exe` 接入。

## 发布构建方式

新增 `build.ps1 -LibraryOnly`，仅编译、归档恢复出的原生代码，不需要诊断用的大型生成输入、原 APK 或原生游戏库。CMake 提供 `-DPVZ2_BUILD_DIAGNOSTICS=OFF` 对应选项（本轮未执行 CMake）。源码发布保留检查程序和生成脚本，但不携带嵌入游戏资源的生成输入、原生库、APK、密钥或私有存档。

GitHub 同步内容包括 `native_recovered` 源码/构建文件、恢复脚本、各轮报告与构建摘要。公开检出目录会另外实际运行 LibraryOnly 构建；它证明源码库可独立编译，不代表能生成游戏 APK。
