# 第六轮恢复结果

本轮补出了最后 **2 个原先超时的函数伪代码**，主库累计 **55,207 个不同地址的函数输出**。此前统计的 28 个困难条目现在都已有选定 C 输出，其中部分仍是带实验边界的候选。

- 两个新函数：用途、接口、伪代码与仿真样例（本地材料）
- 最后一个截断点：76 个分支的扩展候选（本地材料）
- 最新统一函数目录（本地材料）
- 沿用的类型目录：2,174 个类型、6,232 条字段记录（本地材料）
- 本轮采用版本及前轮来源（本地材料）

## 验证结果

| 项目 | 结果 |
| --- | ---: |
| 新补出的函数 | 2 |
| 新登记的 ARM 主分支项 | 168 |
| Thumb 辅助函数仿真输入 | 76 / 76 通过 |
| 16 位、32 位格式化原指令样例 | 14 / 14 通过 |
| 统一目录中含 halt_baddata 的条目 | 0 |

两个新函数的原指令在仿真中分别正确输出普通文字、中文、正负十进制、十六进制和补零文本；写出回调失败的样例返回 -1。仿真使用原 ELF 指令和测试回调，没有运行游戏，也没有验证伪代码的完整等价性。

最后一个已知截断点也已得到 76 个分支的扩展伪代码候选。它仍保留 **277 条诊断注释**，没有据此宣称全部代码正确。主库其它输出中仍有 319 个地址含跳转表未恢复的提示，已整理为 后续核对目录（本地材料）。

实验只写入新的独立 Ghidra 工程；原 APK、原生库字节、前轮主工程和历史结果保留。这些仍是反编译伪代码及分析线索，不是可直接重新编译的完整原始工程。

结构与完整性核验（本地材料）；有限 CPU 仿真记录（本地材料）。
