# 从反编译结果到可构建工程

当前纯源码引擎进度见 [完全从源码编译进度](完全从源码编译进度.md)。第二十九轮支持十一种具体数据类，Cowboy DangerRoom 的 5/5 个声明可创建并连接四个本包模块，仍有 16 条外部符号引用未闭合；现有可构建 APK 仍使用原生库与大量 Smali，新 C++ 尚未替换 Android 游戏引擎。下文保留 APK 重建路线的验证记录。

当前结果以 [离线修复与源码恢复第三阶段](离线修复与源码恢复第三阶段.md) 为准：85 个 Java 文件、169 个类参与构建；独立离线包可以进入首关，本地玩家资料冷启动保留。下方链接保留此前框架阶段的记录。

**已做成可以实际构建 APK 的重建工程，但还不是完整的 Java/Kotlin/C++ 源码。**

完整源码化可以作为后续重建方向推进；仅凭 APK 不能保证精确找回原始开发工程，更不能把已有伪代码直接变成可靠的完整 C++ 源码。本轮先完成了可验证的构建基础。
