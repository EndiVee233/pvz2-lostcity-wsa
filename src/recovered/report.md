# 离线修复与源码恢复记录

本仓库新增了一份从用户提供的《植物大战僵尸2》中文版 1.7.5 APK 中恢复的 Java 层源码，以及 WSA 离线运行修复与验证记录。公开内容不包含原始 APK、游戏资源、原生 `.so`、签名密钥、设备存档或本机路径。

## 离线运行修复

在独立测试包中加入显式 Manifest 元数据 `pvz2.reconstruction.offline=true`。启用后，`AndroidHttpProxy.GetNetworkStatus()` 返回网络不可达状态，离线 HTTP 事务立即走原错误回调，避免游戏无限停在“服务器通讯中”遮罩。未设置该元数据时保留原网络行为。

独立测试包还将玩家资料写入其应用私有目录，避免 WSA Android 13 下跨应用 UID 访问原版外部目录时权限不足。实际 WSA 验证进入“神秘埃及－第1天”教程；强制结束并冷启动后，本地玩家资料仍保留。已有资料时仍可能出现可点击“跳过”的云存档故障提示。没有伪造登录、云存档、支付或奖励成功。

已验证离线 APK SHA-256：`a84c77d52a4cc2724a5828c95f3b0eb1506c37420a85d4851e55e66091483e92`。APK 文件约 1.4 GB，未提交到 Git 仓库；本仓库只保存源码、校验记录和说明。

## Java 源码范围

- 85 个 Java 源文件可编译，生成 169 个类：启动入口 1 个文件/9 个类，主 DEX 的 `com.popcap` Java 层 84 个文件/160 个类。
- `com.popcap` 命名空间还有 1 个旧编译器生成的枚举跳转表以原 Smali 保留。
- 32 个原生方法声明、311 个 R/BuildConfig 常量与原 DEX 对照一致。
- 原 APK 共有 8 个 DEX、50,457 个类描述符；其他 SDK 托管代码仍大量使用 Smali，二进制资源表及 8 个原生库继续依赖原 APK。

## 验证

- WSA 对原始输入 DEX 与重建 DEX 的行为对照：每边 433 项通过（框架 358 项、服务模块 75 项）。这些探针不调用真实通知、奖励或支付服务。
- 离线游戏界面实测：欢迎页、主菜单、首关教程及本地资料冷启动保留。
- 原生网络桥接：对原 ARM 指令进行 11 项有界仿真，确认网络状态缓存布局和两个次级基类析构跳板。JNI 回调由仿真钩子提供，不能视为完整引擎测试；C++ 片段没有编译或链接。
- 完整战役、长时间存档升级、云端合并、支付、分享及系统通知尚未完整验证。

## 文件位置

- `src/recovered/bootstrap/`：恢复的 Java 启动入口。
- `src/recovered/game_bridge/`：84 个主 DEX `com.popcap` Java 文件。
- `src/recovered/tests/`：桌面/Android 行为探针源码，不打入 APK。
- `src/recovered/native/`：网络桥接布局片段、ARM 仿真与结果。
- `src/recovered/tools/`：接口提取与校验脚本。
- `src/recovered/*validation*.json`：构建/API/WSA 结果记录。设备序列号、进程号和本地存档哈希已从公开副本删除。

## 构建限制

这些文件是维护用的恢复源码快照，不是原始完整工程。要重建 APK，仍需合法取得原版 APK、解包得到的 Smali/资源、Android/JDK 工具链，并按工作区原工程布局准备仅供编译的 API 声明。编译用 API JAR 中没有原实现，也不应作为应用代码打包。原生游戏引擎仍依赖原始二进制库。
